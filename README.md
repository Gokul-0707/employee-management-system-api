# Employee Management System API

A REST API for managing employee records.

## Technologies

- Python
- FastAPI
- MySQL
- SQLAlchemy
- Pydantic
- Swagger UI

## Features
- Create employee
- Get all employees
- Get employee by ID
- Update employee
- Delete employee
- Email validation
- Duplicate email prevention
- Salary validation
- Environment variable configuration

## Run the Project
pip install -r requirements.txt
python -m uvicorn main:app --reload
